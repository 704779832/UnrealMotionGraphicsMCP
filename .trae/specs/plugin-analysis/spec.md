# UmgMcp 插件分析 - 产品需求文档

## 概述
- **摘要**: UmgMcp 是一个 Unreal Engine 5 插件，提供 AI 辅助的 UMG (Unreal Motion Graphics) 工作流程，通过将 UMG 资产转换为 JSON 格式实现版本控制，并提供完整的 API 来操作 UMG 组件、蓝图、动画和材质。
- **目的**: 解决 UMG 资产版本控制问题，提供 AI 辅助设计能力，简化 UMG 开发流程。
- **目标用户**: UE5 开发者、UI 设计师、AI 辅助设计使用者。

## 目标
- 实现 UMG 资产的版本控制（通过 JSON 格式）
- 提供完整的 API 来操作 UMG 组件、蓝图、动画和材质
- 支持 AI 辅助设计工作流程
- 提供 HTML 到 UMG 的转换能力
- 实现与 Gemini AI 的集成

## 非目标（超出范围）
- 不支持 UE4 或更早版本
- 不提供完整的 UI 设计工具
- 不替代 Unreal Editor 的内置功能
- 不支持实时多人协作编辑

## 背景与上下文
- 传统 UMG 资产使用二进制 .uasset 格式，难以进行版本控制和协作
- AI 辅助设计需要程序化访问和修改 UMG 资产
- 现有工具缺乏完整的 API 来操作 UMG 组件、蓝图、动画和材质

## 功能需求
- **FR-1**: UMG 组件操作 - 创建、修改、删除 UMG 组件
- **FR-2**: 蓝图编辑 - 操作蓝图节点、变量和函数
- **FR-3**: 动画管理 - 创建和编辑 UMG 动画
- **FR-4**: 材质编辑 - 操作材质节点和连接
- **FR-5**: 文件转换 - 在 UMG 和 JSON 之间转换
- **FR-6**: 上下文管理 - 跟踪当前编辑的资产
- **FR-7**: HTML 解析 - 将 HTML 转换为 UMG 布局
- **FR-8**: AI 集成 - 与 Gemini AI 交互

## 非功能需求
- **NFR-1**: 性能 - 操作响应时间不超过 1 秒
- **NFR-2**: 可靠性 - 操作失败时提供清晰的错误信息
- **NFR-3**: 可扩展性 - 支持添加新的工具和功能
- **NFR-4**: 兼容性 - 支持 UE 5.6 及以上版本
- **NFR-5**: 安全性 - 安全处理用户输入和网络通信

## 约束
- **技术**: 基于 Unreal Engine 5.6 API，使用 C++ 和 Python
- **依赖**: 需要 Python 环境和 Gemini CLI
- **平台**: 仅支持 Win64 平台

## 假设
- 用户已安装 Unreal Engine 5.6 或更高版本
- 用户已配置 Python 环境和 Gemini CLI
- 用户了解基本的 UMG 开发概念

## 验收标准

### AC-1: UMG 组件操作
- **给定**: 打开的 UMG 资产
- **当**: 调用创建、修改或删除组件的 API
- **则**: 组件应按预期创建、修改或删除
- **验证**: `programmatic`

### AC-2: 蓝图编辑
- **给定**: 打开的蓝图资产
- **当**: 调用添加节点、变量或函数的 API
- **则**: 蓝图应按预期更新
- **验证**: `programmatic`

### AC-3: 动画管理
- **给定**: 打开的 UMG 资产
- **当**: 调用创建或编辑动画的 API
- **则**: 动画应按预期创建或更新
- **验证**: `programmatic`

### AC-4: 材质编辑
- **给定**: 打开的材质资产
- **当**: 调用添加节点或连接的 API
- **则**: 材质应按预期更新
- **验证**: `programmatic`

### AC-5: 文件转换
- **给定**: UMG 资产或 JSON 文件
- **当**: 调用转换 API
- **则**: 资产应成功转换为目标格式
- **验证**: `programmatic`

### AC-6: HTML 解析
- **给定**: HTML 内容
- **当**: 调用 HTML 解析 API
- **则**: HTML 应转换为有效的 UMG 布局
- **验证**: `human-judgment`

### AC-7: AI 集成
- **给定**: 配置好的 Gemini CLI
- **当**: 启动 MCP 服务器
- **则**: AI 应能够通过 API 操作 UMG 资产
- **验证**: `human-judgment`
